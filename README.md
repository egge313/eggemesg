# eggemesg
Egge's Messenger facilitates communication over Tor while
employing strong cryptography. It exists as a proof of concept and
aims to support anonymous and safe communication. Once you have
established that you are messaging with Alice, you will be pretty
certain that it is indeed Alice you are talking to. Safety comes from encrypted
messages and the fact that Tor messaging is encrypted, too. Thanks to Tor,
there is anonimity, i.e. no one know that you are communicating, and no one
knows whi you are communicating with.
